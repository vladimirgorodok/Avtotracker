# Автотрекер

Личная база данных водителя-одиночки: путевые листы, перевозки с маршрутом из точек, места, заправки, финансы.
Работает без интернета, данные хранятся на телефоне (SQLite).

## Что есть (этап 1)
- Путевые листы: автоподстановка одометра и топлива из прошлого листа, пробег, расход, средний л/100 км, контроль ошибок.
- Перевозки: маршрут из точек «Погрузка/Выгрузка», статус каждой точки, автоначисление (по умолчанию 10 500 за 2 точки + 1 000 за каждую следующую, ставки в настройках).
- Справочники: фирмы, места (координаты, контакт, навигатор, звонок), грузы, АЗС, автомобили с периодами.
- Заправки (бочка / АЗС), финансы (начислено / поступило, месяц оплаты).
- Экспорт: ZIP с CSV, Excel, JSON-копия, PDF-отчёт. Импорт: ZIP и JSON, совпадающие записи не меняются.
- ИИ-помощник через OpenAI-совместимый API (адрес, ключ и модель вводятся в настройках приложения).

## Планы
- Этап 2: облачная синхронизация (Supabase), фото документов.
- Этап 3: доработка ИИ, PDF с кириллицей.

## Разработка
```
npm ci
npm run dev        # браузер
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```
APK собирается автоматически GitHub Actions и публикуется в Releases (тег `latest`).

Секреты (ключи API, `.dev.vars`, keystore) в репозиторий не коммитятся.
