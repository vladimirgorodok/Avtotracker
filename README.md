# АвтоБаза

Личная база данных водителя-одиночки: путевые листы, перевозки с маршрутом из точек, места, заправки, финансы.
Работает без интернета — данные лежат на телефоне в базе SQLite, а копия по желанию уезжает на ваш Яндекс Диск.

## Скачать

**APK:** https://github.com/vladimirgorodok/Avtotracker/releases/tag/latest → `avtobaza-debug.apk`

Скачайте файл на телефон, откройте и разрешите установку из неизвестных источников.
Сборка создаётся автоматически при каждом изменении ветки `main`.

Новая версия ставится **поверх старой**, удалять приложение и заново всё настраивать не нужно: все сборки
подписываются одним и тем же ключом из репозитория (`android/keystore/avtobaza.jks`). Если у вас установлена
версия, собранная до 13.11.2026 (она подписывалась случайным отладочным ключом), её придётся один раз удалить —
дальше обновления будут ставиться поверх. Чтобы не вводить настройки заново, перед этим сохраните их в файл:
**Настройки → «Настройки в файле» → «Сохранить настройки в файл»**, а после установки — «Загрузить настройки
из файла». Номер установленной сборки виден там же, в **Настройки → «Данные и диагностика»**.

## Обновление из приложения

Приложение само проверяет, нет ли на GitHub сборки новее: при запуске (не чаще раза в сутки) и кнопкой
**Ещё → Обновление → «Проверить обновление»**. Если вышла новая версия, её можно скачать и установить
прямо из приложения: файл скачивается внутри приложения, проверяется по контрольной сумме с GitHub, а
затем передаётся системному установщику Android — установку всегда подтверждает человек. Проверку при
запуске можно выключить переключателем на том же экране (**Настройки → «Обновление приложения»**).

Установка новой версии **поверх старой** — это разрешение Android «из неизвестных источников» для АвтоБазы:
при первом обновлении приложение откроет системный экран, где его включают один раз.

## Что умеет

**Путевые листы.** Дата выезда, одометр и топливо при выезде и сдаче, автоподстановка одометра и топлива из
предыдущего закрытого листа, пробег, расход топлива и средний расход л/100 км, сравнение с нормой автомобиля,
контроль ошибок (одометр меньше предыдущего, дата сдачи раньше выезда, выгрузка раньше загрузки, перерасход).

**Перевозки.** Маршрут — список упорядоченных точек «Погрузка» и «Выгрузка»; возможны варианты «2 погрузки →
3 выгрузки». У точки: фирма, место из справочника (список мест фильтруется по выбранной фирме), плановая и
фактическая дата, статус, тип загрузки (задняя, боковая, верхняя), груз. Вес указывается у самой поездки, а не
у точек. У новой выгрузки дата по умолчанию — на день позже предыдущей точки.

На карточке точки есть кнопка «Выполнен»: она ставит фактическую дату сегодняшним днём, и поездка сама
переходит к следующей точке; когда выполнены все точки, поездка закрывается и открывается её карточка для
сохранения начисления. Текущая (незакрытая) поездка стоит в списке первой, остальные — свежие сверху. Значок
в списке показывает ход поездки («В плане» / «Выполнена»), а деньги — отдельная плашка «К начислению» или
«Начислено», поэтому в фильтре «Выполнены» видны и уже начисленные перевозки. На главной есть блок «Следующая
точка»: фирма с логотипом, адрес, координаты, контакт и примечания — всё кликабельное, а координаты ведут в
приложения навигации телефона.

**Начисление.** По умолчанию 10 500 за 2 базовые точки плюс 1 000 за каждую следующую. Ставки меняются в
настройках. Начисление создаётся автоматически при закрытии листа датой последней выгрузки; на один лист
может приходиться несколько начислений. «Поступило» привязано к месяцу оплаты, а не к поездкам.

**Справочники.** Фирмы (с логотипом), места (адрес, координаты, контакт, тип загрузки, типовой груз),
грузы, АЗС, автомобили (тягач и прицеп с периодами использования и связками).

**Заправки.** Дата, объём, источник — бочка или АЗС. Без цены.

**Финансы.** Начислено и поступило, месяц оплаты, итоги Начислено / Оплачено / Остаток. Суммы без знака ₽.

**Документы.** Фото накладных и чеков с камеры. Снимки сжимаются, лежат отдельно от базы; у каждого
документа есть миниатюра и подпись.

**Обмен данными.** Экспорт: Excel (по листу на таблицу), JSON-резервная копия, отчёт PDF за месяц,
печать отдельного путевого листа в PDF. В отчёте за месяц по каждому листу видно и тягач, и прицеп, а под
таблицами идут строки «Итого»: где количество (листов, перевозок, заправок, точек), где сумма (пробег,
заправлено, вес, начислено). Импорт — из JSON-копии: совпадающие записи остаются без изменений.
На экране «Обмен данными» видно, сколько записей в каждой таблице, и лишнюю таблицу можно
очистить отдельно, не трогая остальное.

**Обновление.** **Ещё → Обновление**: приложение смотрит, нет ли на GitHub сборки новее установленной,
скачивает её и передаёт системному установщику Android (установку подтверждает человек). Проверка идёт и
при запуске — тихо, не чаще раза в сутки.

**Настройки в файле.** Ставки, оформление, адрес и ключ ИИ-помощника, вход в Яндекс Диск
сохраняются в отдельный JSON-файл и загружаются обратно: **Настройки → «Настройки в файле»**. Пригодится при
смене телефона, сбросе или переустановке приложения — вводить всё заново не нужно. Справочники и поездки
переносятся полной копией в «Обмене данными»; файл настроек тоже принимается обычным импортом JSON.

**ИИ-помощник.** Видит сводку по вашим данным — листы, перевозки, топливо, деньги, справочники — и отвечает на
вопросы по ним. Без ключа отвечает на частые вопросы прямо на телефоне: итоги месяца, расход топлива, открытые
листы, замечания по заполнению, справочники. С ключом работает любой сервис с OpenAI-совместимым API: адрес, ключ
и модель вводятся в настройках, есть проверка подключения и список моделей. Ответы можно читать потоком, копировать
и хранить на устройстве. Ключ в коде не хранится. В настройках ключ можно показать, а рядом видно, сколько знаков
введено и с чего ключ начинается — так сразу заметно, если скопилась только часть ключа или вставилось не то
значение. Если сервис отклонил ключ, приложение подсказывает проверить его целиком, а при обрыве сети пишет
об этом понятными словами.

**Заявка из файла (ИИ-помощник → «Заявка из файлов»).** К помощнику можно приложить заявку файлами: фото, скан,
текст, CSV или Excel — сразу несколько (до 8; фото сжимаются, таблицы читаются как текст). А если заявка пришла
сообщением, письмом или по телефону, её можно просто **вписать или вставить текстом** в окно «Текст заявки» на том же
экране — оно уходит помощнику наравне с файлами, и вместе с ними тоже (например, фото накладной плюс текст из
мессенджера). Видно, сколько знаков возьмут из текста. Пока помощник работает,
на экране виден ход дела по шагам: «Читаю файлы» (с именем текущего файла), «Отправляю помощнику»,
«Получаю ответ» (с числом уже полученных знаков и секундами), «Разбираю ответ», «Сверяю фирмы и места со
справочником» — с полосой выполнения, чтобы было видно, что приложение не зависло. Помощник собирает из файлов
перевозку: название рейса, груз, вес, сумму, машину, точки маршрута с датами, адресами, координатами и контактами.
Дальше он сверяет фирмы и места со справочником по нескольким признакам одновременно — названию, адресу,
координатам и привязке к фирме — и по каждому предлагает выбор: **добавить новое**, **использовать существующее**
(при желании дополнить его адресом, контактом и координатами из заявки) или **пропустить**. Похожесть показана
словами и процентами, а решение всегда за вами.

Все поля, которые берутся из справочника, сделаны списками: **груз** — из справочника грузов, **фирма** — из
справочника фирм (и у каждой точки тоже, а не только у места), **место** можно выбрать из справочника списком или
кнопкой «Найти или создать место». В каждом таком списке у записи виден её логотип или значок — и в самом поле, и в
раскрытом списке: у фирмы логотип, у груза значок, у АЗС и техники тоже свои картинки. В длинных списках (от шести
записей — фирмы, места, грузы, АЗС, техника) сверху есть поиск: наберите несколько букв, и останутся только
подходящие записи; на коротких списках поиск не показывается, чтобы не выскакивала клавиатура на каждый выбор.
В любом таком списке есть пункт «Другое — вписать название»: если нужного нет,
название вводится руками и попадёт в справочник при создании поездки. Что разобралось — видно и правится прямо на
экране: порядок точек, типы «погрузка/выгрузка», даты, места, фирмы, примечания. Кнопка «Создать поездку» заводит
перевозку со статусом «В плане», привязывает её к открытому листу, считает начисление по ставкам и добавляет
недостающий груз в справочник. Фотографии заявки прикладываются к созданной поездке как документы, а список
«чего нет в заявке» (вес, контакт, дата) напоминает, что дозаполнить в её карточке. Ответ помощника можно
посмотреть целиком — и убедиться, что лишнего он не придумал.

**Значки и логотипы (ИИ-помощник → «Значки и логотипы»).** Подбор картинки по названию: фирме — логотип,
грузу, АЗС и технике — значок. Ключ и аккаунт не нужны, картинки берутся из открытых источников — наборы значков
Iconify (в том числе фирменные логотипы: logos, thesvg, simple-icons, arcticons), Викисклад с настоящими логотипами
и фотографиями, Викиданные (официальный сайт и логотип фирмы — так находятся российские фирмы, которых нет в
зарубежных наборах значков), а когда адрес фирмы известен — значки её сайта (Яндекс, Google, DuckDuckGo, Clearbit).
Показывается до 30 картинок сразу, чтобы было из
чего выбрать, с подписью, откуда каждая пришла; неподошедшую можно не брать. Если по одному написанию ничего не
нашлось, поиск продолжается по другим вариантам названия: убираются и добавляются организационные формы
(«ООО», «АО», «ОАО», «ЗАО», «ПАО», «ИП») в разных порядках, название пишется латиницей, а для грузов
подставляются понятные всем наборам слова (кирпич → brick, цемент → cement, зерно → grain и так далее). ИИ-помощник,
если он настроен, готовит эти варианты сам и подсказывает адрес сайта; без ключа всё то же самое делается на
устройстве, поэтому поиск работает и без интернета-помощника. Кнопка «Найти» есть прямо в карточках справочника —
у фирм, грузов, АЗС и автомобилей, — а на отдельном экране можно выбрать, куда поставить найденную картинку, или
сохранить её файлом. Нынешняя картинка записи видна и в её карточке (крупно, как в справочнике автомобилей), и в
окне подбора — сразу понятно, что именно заменяется. Ход поиска виден по шагам, а если какой-то источник недоступен,
остальные всё равно отвечают.
Если найденное не подошло, под результатами есть кнопка **«Из файла»** — своя картинка вместо найденной. В карточке
справочника она встанет в поле логотипа и сохранится вместе с записью, а на отдельном экране сразу уйдёт в выбранную
запись и откроется её карточка — там новую картинку видно и можно поправить.
Поиска картинок Яндекса среди источников нет: у Яндекса нет бесплатного открытого API для этого (поиск по
картинкам закрыт для приложений, а платный Search API требует ключ и аккаунт в Yandex Cloud), поэтому от Яндекса
взято то, что доступно без ключа, — значок сайта по адресу фирмы.

**Поиск по всему.** Поле поиска вверху «Главной» и пункт «Поиск по всему» в «Ещё → Данные» открывают поиск по всей
базе сразу: номер путевого листа, машина и её номер, фирма, место и адрес, груз, АЗС, сумма, дата или заметка.
Находки собраны отдельным списком по разделам (листы, поездки, заправки, финансы, техника, фирмы, места, грузы,
АЗС) — видно, сколько нашлось в каждом, а нажатие на строку открывает карточку записи. Сверху — счётчик находок,
если в разделе их больше двадцати, показаны первые с подсказкой уточнить запрос. Запрос сохраняется в адресе: из
карточки можно вернуться к прежним находкам. Поиск идёт на устройстве, интернет не нужен.

**Порядок списков.** Везде, где показаны записи, свежие идут сверху: путевые листы — по дате выезда, поездки —
сначала незаконченные, затем свежие, заправки и финансы — по дате (в один день сверху та запись, что заведена позже),
документы карточки — по времени добавления. Поездки и заправки внутри путевого листа тоже идут от свежих к старым, а
в печатном листе перевозки остаются по порядку смены. Справочники (фирмы, места, грузы, АЗС, техника) — по названию,
точки маршрута — по порядку в поездке.

**Прочее.** Экран «Ещё» разделён переключателем на две половины: **Данные** (поиск по всему, путевые листы, поездки,
заправки, финансы, техника, справочники) и **Сервисы** (Яндекс Диск, обмен данными, помощник, значки, настройки) — список
не растягивается на простыню. Фильтр по месяцу — в списке только те месяцы, где есть данные,
навигатор и звонок из карточки места, GPS-координаты,
светлая и тёмная тема, две цветовые гаммы на выбор — тёмно-синяя (как на значке) и бирюзовая,
анимированная заставка при запуске.

**Планшетный вид.** На широком экране в альбомной ориентации приложение само перестраивается: меню уходит
вертикальной рельсой влево, карточки и списки записей становятся в две колонки, шторки показываются окном по
центру, а содержимое не растягивается на весь монитор. Телефон в альбомной ориентации и планшет в портрете
остаются в обычном виде. В **Настройки → «Отображение» → «Вид»** можно закрепить вид руками: «Автоматически,
по экрану», «Телефон — узкая колонка» или «Планшет — широкий вид»; выбор уезжает в файл настроек вместе с
остальными.

## Яндекс Диск (по желанию)

Способ держать данные на всех устройствах — файлы в вашем Яндекс Диске. Ключи и регистрация не нужны:
вход по логину и «паролю приложения». Данные и значки хранятся отдельно, как в «Платежах»:

- `avtobaza-<дата>.json` — данные: справочники, путевые листы, поездки, заправки, финансы и настройки.
  Картинок в файле нет, поэтому он лёгкий и уходит быстро;
- `avtobaza-icons-<дата>.zip` — архив значков: логотипы фирм, машин, грузов, АЗС и фотографии документов.
  Картинки раскладываются по записям по названию (у техники — ещё и по номеру машины): пустые поля
  заполняются, уже подобранные значки не затираются.

В облаке хранятся последние несколько копий каждого вида (число настраивается), старые удаляются.
Если значки не менялись с прошлой выгрузки, архив заново не отправляется — только лёгкий файл данных.
Та же инструкция есть внутри приложения: **Ещё → Яндекс Диск → «Как получить пароль приложения»**.

1. Откройте https://id.yandex.ru/security/app-passwords и создайте пароль типа **«Файлы»**
   (в некоторых версиях он называется «WebDAV-клиент для Яндекс Диска»). Обычный пароль от Яндекс ID не подойдёт.
2. В приложении: **Ещё → Яндекс Диск**, введите логин, пароль приложения и нажмите «Проверить подключение».
3. Дальше — «Обменять сейчас» или автоматический обмен: после изменений приложение выгружает свежую копию,
   при запуске сверяется с облаком, а при уходе в фон сохраняет невыгруженное. Загрузка из облака по умолчанию
   дополняет и обновляет записи; замена всего — отдельной галочкой.

Обмен идёт по протоколу WebDAV прямо с телефона. Обычный сетевой мост Android методы WebDAV (`PROPFIND`,
`MKCOL`) не пропускает, поэтому в приложении есть свой небольшой обработчик
`android/app/src/main/java/ru/avtobaza/app/WebDavPlugin.java` на OkHttp. В браузере на компьютере обмен
не работает — Яндекс не пускает чужие страницы, — и приложение говорит об этом словами. По WebDAV Яндекс
открывает Диск подписчикам Яндекс 360.

## Защита данных

Данные хранятся в файле базы внутри приложения. Чтобы их нельзя было потерять случайно:

- при запуске рядом с базой остаётся копия (`avtobaza.db.bak`) — состояние базы на момент запуска;
  вернуть её можно в **Ещё → Обмен данными → «Защита данных»**. Пустая база копию не затирает:
  если данные пропали, последняя целая копия остаётся на месте;
- если файл базы есть, но прочитать его не удалось, приложение открывается с пустой базой, **не перезаписывая**
  файл, и держит предупреждение на экране: сначала нужно вернуть копию, импортировать свою резервную копию
  или осознанно нажать «Продолжить с пустой базой» (непрочитанный файл откладывается как `avtobaza.db.broken`);
- если базу не удалось записать на устройство, об этом сразу сообщается — молча данные не теряются;
- перед полной очисткой данных и перед загрузкой из облака «заменой» копия делается автоматически;
- пустая база не выгружается в облако поверх копии с данными: выгрузка останавливается с объяснением,
  иначе свежая пустая копия затёрла бы единственную целую;
- база прежнего имени (`avtotracker.db`, до переименования приложения) подхватывается, если новой нет.

Надёжнее всего держать ещё и резервную копию файлом: **Ещё → Обмен данными → «Скачать резервную копию (JSON)»**
и хранить её вне телефона.

## Разработка

```bash
npm ci
npm run dev            # разработка в браузере
npm run smoke          # 524 проверки: схема, расчёты, начисление, PDF, экспорт/импорт,
                       #   резервная копия JSON, отмена переноса,
                       #   даты-моменты времени, статусы по данным, защита справочников от дублей,
                       #   порядок перевозок и статусы «выполнена / начислено», следующая точка,
                       #   навигационные ссылки, разбор заявки из файлов и из вписанного текста, сверка со справочником,
                       #   ход разбора по шагам, выбор фирмы и места вручную, перенос настроек файлом,
                       #   подбор логотипов и значков по названию (Викиданные, значки сайтов),
                       #   логотипы в списках выбора и поиск по списку, разделы экрана «Ещё»,
                       #   поиск по всему (листы, поездки, деньги, справочники), документы,
                       #   порядок списков (свежие сверху) и своя картинка файлом,
                       #   Яндекс Диск (разбор ответов WebDAV, файл данных без картинок, архив значков,
                       #   выгрузка и загрузка с чисткой старых копий, родной обработчик для Android),
                       #   защита данных (копия базы, непрочитанный файл, пустая выгрузка в облако),
                       #   планшетный вид (альбомная ориентация: меню слева, записи в две колонки),
                       #   ИИ-помощник, оформление, сборка всех экранов
npm run build          # сборка веб-части
npm run android:apk    # сборка APK локально (нужен Android SDK)
```

Структура:

- `src/db/` — схема базы, миграции, доступ к данным, наполнение справочников,
  хранение файла базы и её копии (`storage.ts`);
- `src/lib/` — расчёты, действия над данными, экспорт и импорт, документы,
  обмен с Яндекс Диском (`webdav.ts` — протокол, `yadisk.ts` — файлы данных и архив значков,
  `native-webdav.ts` — родной обработчик на телефоне, `yadisk-auto.ts` — автоматический обмен),
  подбор логотипов и значков (`pictures.ts`), поиск по всей базе (`search.ts`);
- `src/pages/` — экраны приложения;
- `src/ui/` — общие элементы интерфейса, поиск картинок (`PictureSearch.tsx`), заставка (`Splash.tsx`);
- `src/dev/smoke.ts` — проверка ядра без телефона;
- `assets/make-icons.py` — значок приложения: берёт присланный логотип `assets/logo-source.png`
  (светящаяся «стеклянная» фура на тёмной плитке), вырезает плитку и растеризует её в ресурсы Android
  (`python3 assets/make-icons.py`, нужен `rsvg-convert`);
- `android/app/src/main/java/ru/avtobaza/app/WebDavPlugin.java` — родные запросы к Яндекс Диску
  по WebDAV через OkHttp: методы `PROPFIND` и `MKCOL` обычный сетевой мост Android не пропускает.

Приложение рисуется во весь экран (Android 15+ требует этого для `targetSdk 36`), поэтому отступы
под строку состояния и полосу жестов берутся из переменных `--safe-area-inset-*`, которые Capacitor
подставляет в документ; в CSS они доступны как `--safe-top` / `--safe-bottom` / `--safe-left` / `--safe-right`.

## Ограничения

- Сборки подписываются постоянным ключом `android/keystore/avtobaza.jks` (пароль рядом, в
  `android/keystore.properties`). Ключ лежит в открытом репозитории намеренно: только одна и та же подпись
  позволяет Android ставить новую версию поверх старой, не стирая настройки. Приложение личное, в Play Market
  не публикуется, автообновления нет — APK ставится вручную. Для публикации в Play Market понадобится свой ключ.
- Секреты (ключи API, `.dev.vars`) в репозиторий не коммитятся; исключение — ключ подписи APK, см. выше.
- Разбор заявки из файлов зависит от модели: чтобы помощник читал фотографии, нужна модель, понимающая
  картинки. Всё распознанное показывается на экране до создания поездки, поэтому ошибку видно сразу и её
  можно поправить руками — в базу и справочники ничего не попадает без подтверждения.
- Подбор значков и логотипов идёт по открытым источникам, поэтому требует интернета. Если картинку не
  удалось скачать (источник закрыт для приложения), она сохраняется ссылкой: на телефоне логотип будет виден,
  но офлайн и в облако сама картинка не попадёт — тогда лучше выбрать другую или загрузить файлом. Часть
  источников может быть недоступна из России; поиск не падает — остальные источники всё равно отвечают,
  а что не ответило, приложение пишет словами.
